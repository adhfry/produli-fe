## 1. Sumber Warna Resmi (verbatim dari user — konversi ke `@theme`, JANGAN buat `tailwind.config.js`)

Convert semua warna di bawah jadi custom property di dalam blok `@theme { }` pada `assets/css/main.css` yang sudah ada, pola `--color-{nama}-{shade}: #hex;` (mis. `--color-primary-500: #00A59A;`), supaya otomatis tersedia sebagai class `bg-primary-500`, `text-primary-900`, dst — cara Tailwind v4 membaca token warna, bukan lewat `theme.extend.colors` di file JS.

## 2. Cara Pakai Warna (semantik, bukan asal pilih)

- `primary` (teal) — tombol utama, badge, highlight, link aktif
- `secondary` (hijau) — status "Selesai"/"Sehat"/GPS tervalidasi/sukses di konteks lapangan
- `accent` (navy) — heading utama, navbar, footer, sidebar, teks dominan
- `surface` — latar body (bukan putih polos — beri kesan "medis bersih" sesuai catatan user)
- `danger`/`warning`/`success`/`info` — sesuai makna standar (risiko berat/sedang/status baik/info)
- `neutral` — pengganti abu-abu default Tailwind
