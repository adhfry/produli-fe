Membangun Ekosistem Digital

Platform terintegrasi yang menjembatani data klinis dengan penanganan di lapangan secara otomatis dan aman.

Berbasis Data Laboratorium

Terintegrasi langsung dengan SiLAKES. Data hasil lab menjadi pemicu otomatis klasifikasi risiko tanpa input manual.

GPS Validation

Sistem memvalidasi lokasi kader saat kunjungan pasien dengan dua tingkat presisi radius, mencegah manipulasi laporan.

Dashboard Analitik

Visualisasi sebaran risiko kesehatan masyarakat dan performa kader, dari level Dinas hingga Puskesmas.

Mobile First / Offline Ready

Dirancang untuk daerah pelosok. Kader tetap bisa input data kunjungan meski tanpa sinyal, tersinkronisasi saat online.

Dokumentasi Digital Aman

Watermark otomatis, validasi EXIF, dan penyimpanan Object Storage MinIO terisolasi untuk tiap foto kunjungan.

Monitoring Real-time

Setiap laporan kunjungan kader langsung ter-update di dashboard pimpinan untuk pengambilan keputusan lebih cepat.

Dari Pasif Menjadi Aktif

Laboratorium menjadi pusat pengambilan keputusan — pergeseran dari menunggu pasien datang menjadi penjangkauan proaktif berbasis data.

Klasifikasi Risiko Otomatis

Berdasarkan parameter hasil lab SiLAKES: GDP, Creatinine, Cholesterol, Trigliserida, LDL, Ureum.

Tingkat Risiko Kriteria
Ringan Hanya GDP di atas nilai rujukan
Sedang GDP/Kolesterol Total/Trigliserida/LDL di atas rujukan, belum memenuhi kriteria Berat
Berat Salah satu dari: GDP>120, Creatinine>1.7, Cholesterol>200, Trigliserida>140, LDL>130, Urea>46

Validasi Kunjungan Berlapis

Arsitektur keamanan yang dirancang untuk memastikan integritas laporan kunjungan lapangan.

GPS Geofencing

Dua tingkat presisi radius: 150 meter untuk titik lokasi terverifikasi, 3.000 meter untuk titik perkiraan (centroid desa) sebelum lokasi presisi tersedia.

Kamera Langsung

Wajib dari aplikasi, bukan galeri.

Watermark Otomatis

Waktu, lokasi, dan nama kader tercetak di foto.

Validasi EXIF

Metadata foto disilangkan dengan klaim device.

Deteksi Wajah (opsional)

Kapabilitas tersedia, non-aktif secara default — dapat diaktifkan sesuai kebijakan.

Antrean Offline

Laporan tersimpan aman di perangkat saat tanpa sinyal, sinkron otomatis saat online.
